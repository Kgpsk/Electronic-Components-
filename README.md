## 📖 About This Handbook

A complete, professional reference guide covering **every major electronic component** used in modern electronics — including:

- 🔌 **Power & Conversion** components (transformers, rectifiers, regulators, converters)
- 🧠 **Control & Logic** components (MCUs, transistors, op-amps, logic ICs)
- 🛡️ **Protection** components (fuses, breakers, varistors)
- ⚙️ **Passive** components (resistors, capacitors, inductors)
- 📡 **Sensors** (LDR, thermistor, accelerometer, gyroscope, etc.)
- 💡 **Actuators & Loads** (bulbs, motors, speakers, heaters)
- 🔗 **Connection** components (wires, PCB, connectors, terminal blocks)
- 🧩 **Integrated Circuits** (SoC, ASIC, FPGA, RAM, Flash)

Each entry includes:

| Field | Description |
|-------|-------------|
| **Component Name** | Standard name |
| **Circuit Symbol** | IEC/ANSI standard symbol |
| **Physical Appearance** | What it looks like in real life |
| **Job / Function** | One-sentence plain-English explanation |
| **Real-World Example** | Where you actually see it used |
| **Category** | Power / Control / Protection / Passive / Sensor / Actuator / Connection / IC |
